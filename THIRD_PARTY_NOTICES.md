## Node.js

Source control excludes the Node executable. Runtime preparation copies an installed Node executable and its license to `runtime/NODE-LICENSE.txt`. If the installed distribution has no adjacent license file, setup downloads the matching version's license from the [official Node.js repository](https://github.com/nodejs/node). A local license can also be supplied explicitly. Generated portable packages include the runtime and its license, including the notices for bundled components.
